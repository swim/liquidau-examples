Certified routing examples

Each dataset below has a release built by @liquidau's libraries: mined rules and a cheap edge model settle what they can, certified classifier heads handle the rest, and anything uncertain goes to review. Every number on this page is read from the release files or measured by routing its labelled check file through the router.

Datasets and their classifiers

The promise is what the release certifies for each head on its labelled sample, and ✓ means the head kept it on the check file. "At release" is the release's own held-out test split; the check file is a larger labelled file never used to build the release. Head figures are each head's own firing; the last line is final routing, after the policy's priority picks one route per message.
